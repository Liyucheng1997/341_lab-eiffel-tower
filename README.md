# 埃菲尔铁塔 · 1:1 程序化钢结构模型

基于 Three.js 的埃菲尔铁塔三维模型。全部结构由代码按真实尺寸生成（不依赖外部模型文件），可在浏览器中实时浏览，并模拟一天 24 小时的光照与夜间灯光。

## 运行

```bash
npm install
```

```bash
npm run dev
```

然后打开终端输出的地址（默认 http://localhost:5173）。

## 结构还原

| 项目 | 数值 | 说明 |
|---|---|---|
| 总高 | 330 m | 2022 年加装数字广播天线后 |
| 底座 | 124.9 m × 124.9 m | 柱间净距 74.24 m，单柱截面 25.33 m |
| 一层 | 57.64 m | 平台边长 70.69 m，环梁高约 7 m |
| 二层 | 115.73 m | 平台边长 40.96 m |
| 三层 | 276.13 m | 下层玻璃观景廊 + 上层露天平台 |
| 塔柱曲线 | 外缘半宽 `3.0 + 59.45·e^(-h/88)` | 柱脚倾角约 54°，拟合各层实测宽度 |

生成的构件（`src/tower.js`）：

- **16 根主弦杆**：每根塔柱 4 根，从石砌墩座连续延伸到 273 m，本身是箱形格构（4 根角钢 + 四面 Z 形缀条）
- **塔柱立面**：四个面都有横撑和交叉斜撑（圣安德烈十字），节间高度随截面收窄自动划分；斜撑本身也是格构梁
- **塔柱内部**：每个节点标高处设水平 X 形隔撑
- **二层以上塔身**：四柱合一，立面设大 X 撑，内侧设水平框，中央为电梯井
- **四座装饰大拱**：一层下方，径向格构
- **一层 / 二层环梁**：K 形桁架带，腹杆采用二级格构；楼板格栅、外挑牛腿
- **72 位科学家姓名**：刻在一层饰带上，四个立面各 18 位，按真实朝向排列
- 玻璃地板、玻璃展馆、儒勒·凡尔纳餐厅、栏杆与防护格栅
- 北 / 东 / 西三柱的斜行电梯，以及中央垂直电梯（均有动画）
- 顶部结构：牛腿、埃菲尔办公室、4 根曲线钟楼肋、灯塔灯室、铜穹顶、红白天线、航空障碍灯

细节等级 3（默认）约 **22.5 万根杆件、270 万个三角面**，全部合并成一个 InstancedMesh，一次绘制完成。

## 夜间灯光

- **金色照明**：模拟塔内 336 盏钠灯向上照射钢构件；朝向塔轴的表面更亮
- **闪烁灯**：20,000 只灯泡，入夜后每个整点闪烁 5 分钟（默认从 21:00 开始，打开即可看到）
- **旋转探照灯**：顶部灯塔发出 4 束光
- **真实时刻表模式**：日落后亮灯，23:45 熄灭
- 太阳位置按巴黎（北纬 48.86°）9 月下旬计算，含日出、日落和暮光过渡；周边城市的窗户、路灯在入夜后亮起

## 操作

- 左键旋转，右键平移，滚轮缩放
- 右上角面板可以调整时刻 / 流速、各类灯光、结构细节、阴影、泛光、河面反射，并切换 9 个预设视角
- 显卡较弱时，可将「结构细节」调到 2，并关闭「河面实时反射」

## 精度说明

主要标高和平面尺寸采用官方数据。杆件的截面尺寸、节间划分和缀条节距则按结构规律参数化生成，并对照照片调整，并非逐一取自原始施工图（原塔共 18,038 个构件、250 万颗铆钉）。
